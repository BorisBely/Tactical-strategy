# Combat Balance Tables

## Цель

Этот документ фиксирует стартовые таблицы баланса для тактических перестрелок на дистанции до 100 метров.

Таблицы рассчитаны под текущую систему стрельбы, где точность задается не прямым шансом попадания, а конусом разброса. Итоговый результат ниже показывает ожидаемый диаметр рассеивания на дистанции.

## Базовая Формула

```text
HalfAngleDeg = 0.35 * WeaponBaseDispersion * AmmoSpread * DistanceMultiplier * ModuleMultiplier * UnitRankMultiplier * DebuffMultiplier
SpreadDiameterMeters = 2 * DistanceMeters * tan(HalfAngleDeg)
```

Для базовой демонстрации используются только множители оружия и дистанции.

## Автоматический Огонь

Автоматический огонь использует ту же дистанционную базу, но добавляет множитель по номеру выстрела в непрерывной очереди.

Логика баланса: первый выстрел равен одиночному, 2-3 выстрелы еще контролируемые, 4-5 выстрелы заметно хуже, 6+ выстрелы становятся подавляющим огнем. После отпускания спуска множитель должен восстанавливаться через `RecoilRecoveryPerSecond`.

```text
AutoHalfAngleDeg = SingleHalfAngleDeg * AutoShotMultiplier
```

## Модули

Дистанционные кривые оптики (точность и скорость прицеливания по 0–100 м) описаны отдельно в `OpticDistanceBalance.md` и запекаются в `WeaponAttachmentDefinition.DistanceAimProfile`.

Совместимость:

- `AK only` - модуль ставится только на AK.
- `M4 only` - модуль ставится только на M4.
- `Universal` - модуль подходит к любому оружию, если у оружия есть подходящий слот.

### Дульные модули (Muzzle)

Слот: `Muzzle`. Тормоз и глушитель взаимоисключающи на одном оружии.

Шкала: **тормоз** — быстрее одиночный точный выстрел, но хуже длинная очередь; **глушитель** — тише выстрел и выше эффективная дальность, без влияния на отдачу.

`Прицеливание` — внутренний множитель времени: меньше = быстрее. Для тормоза `0.91` соответствует скорости прицеливания примерно `×1.10`.

## Интерпретация

На 30-50 метрах обе винтовки остаются практичными для стрельбы по центру массы.

На 70-100 метрах M4 mod2 должна заметно выигрывать по стабильности. AK47 остается опасной за счет большего урона за попадание, но сильнее зависит от одиночного огня, ранга юнита и стабилизирующих модулей.
