## Замороженные принципы (не обсуждаем до своего этапа)

### Архитектура

Perception ≠ Combat ≠ Tactical AI. AI не жмёт спуск. Combat executor сам выбирает цель и исполняет огонь, пока #12 не решит иначе связь `AI.EngageTarget` и `Combat.SelectedTarget`.

### Оружие

Weapon Role = **предпочтение, не запрет**. Снайпер может штурмовать. LMG может идти вперёд. Автономно они предпочитают подходящие решения. Игровой приказ и миссия сильнее предпочтения.

### Укрытия

Динамические. **Нет** заранее расставленных CoverPoint_001. Солдат читает геометрию мира.

Два базовых класса: crouch cover и standing cover, плюс partial / corner.

Поиск укрытий:

```text
НЕ: каждый кадр сканировать все укрытия мира
А: NeedCover → локальный query → дешёвый фильтр → 3–10 лучших → дорогая оценка → cache
```

### Lean

Уже существует (Quick / Smooth / Deep). Подключается к тактике, не переписывается.

### Движение

NavMesh = как физически попасть из A в B.  
Tactical Movement = как сделать это с меньшим риском.  
В городе предпочтение вдоль зданий/укрытий, если ситуация опасная. Колонна **разрешена**.

### Формации

Column / Line / Wedge / Compressed Column. В бою формация может распасться на тактические роли (cover / fire / move / rear). Формация — не тюрьма.

### Ранг

Пять рангов меняют **поведение**, не только числа: Recruit, Soldier, Corporal, Veteran, Elite. Один AI + разный уровень компетенции. Не пять разных AI.

### Позы оружия

NotReady / LowReady / HighReady / HipFire / PointAim / Aiming. Боевой gate уже отличает стрелковые позы от нестрелковых.

### Адаптивность (позже обязательно)

resistance → reassessment → reposition → flank → alternate route.

### Under Fire / Wound

Ответ огнём или укрытие → ответный огонь. Ранение: cover → continue if capable.

Milestone **M3 — Competent Soldier** после #15B: Recruit ≠ Veteran ≠ Elite **по наблюдаемому поведению**, не по Excel.

## #13 Dynamic Cover

**Дизайн-док:** `Пехота_система_дизайн.md` **§6.6** + §7 (оптимизация cover query).

**Главный принцип.** Укрытия не расставляет дизайнер. Солдат читает геометрию.

### Классы (фиксируем)

**Cover A (crouch):** стоя не закрывает, в приседе закрывает.  
**Cover B (standing):** закрывает стоящего (и присед).  
**Corner / Partial:** частично закрывает корпус.

Укрытие — не «защищённая точка». Оценка (формулу не фиксировать заранее):

```text
protection  exposure  visibility  fire lane  distance
mission relevance  weapon suitability  movement cost
escape options  danger
```

Смена позиции: `NewScore > CurrentScore + SwitchingCost` — принцип против ping-pong, не утверждённая формула.

### #13.1 Emergency cover

```text
UNDER FIRE → nearest acceptable cover → MOVE → SAFE
```

Не ищем идеал.

### #13.2 Tactical cover

```text
current cover → evaluate alternatives → лучше? → reposition
```

### #13.3 Бой из укрытия

Не: зайти за стену и стоять 30 секунд.

```text
cover → expose → observe → fire → return → reassess
позднее: change side / angle / position
```

**Приёмка.** Юнит на арене без CoverPoints находит crouch/standing/partial. Под огнём берёт ближайшее приемлемое. Не бегает между двумя точками без выигрыша.

**Freeze.** Автоматически определяемое укрытие без hand-authored CoverPoints.

## #14 Tactical Movement / Urban Movement

**Дизайн-док:** `Пехота_система_дизайн.md` **§6.7**.

NavMesh отвечает «как попасть». Тактика отвечает «с минимальным риском».

В городе вдоль стены предпочтительнее середины дороги, если опасно. Факторы пути (формулу не фиксировать):

```text
distance  exposure  cover  LOS  known enemy directions
mission  weapon  formation
```

Формация по пространству и задаче: коридор → колонна; узкий проход → колонна; штурм одного входа → последовательный вход; открытая зона → рассеивание / линия.

### #14.1 Cover-to-cover

```text
Cover A → short movement → Cover B → short movement → Cover C
```

не `A → open field → B`.

### #14.2 Lean / Cornering

Не изобретать lean. Решение → Peek/Lean request → существующая система Quick / Smooth / Deep.

### #14.3 Movement Lean

Не только стоя. Движение вдоль стены → lean → контроль угла → продолжение.

**Freeze.** NavMesh path ≠ Tactical route. После 14B AI использует тело и оружие как часть тактики, не только меняет AIState.

**#14B Readiness.** NotReady / LowReady / HighReady / HipFire / PointAim / Aiming. Точные пороги не фиксировать заранее. PointAim = быстрый close-range; полный Aim = медленнее и стабильнее. Факторы выбора: distance / threat / weapon / movement / mission / geometry / rank.

## #15 Weapon Tactical Profiles + Rank Behaviour

**Дизайн-док:** `Пехота_система_дизайн.md` **§6.8**.

### #15A Оружие

Role = preference ≠ restriction.

| Роль | Предпочитает | Избегает без причины |
|------|----------------|----------------------|
| Sniper | дистанция, LOS, стабильная позиция, overwatch | CQB, first-man entry |
| LMG | широкий сектор, стабильное укрытие, support | не обязан бросаться первым |
| Rifle | универсальная тактика | — |
| Shotgun / CQB | близко, вход, углы, комнаты, быстрое движение | дальняя открытая | 

Оружие влияет не только на Fire, но и на Position / Movement / Cover / Formation slot / Aggression / Preferred distance. Игрок / миссия / вынуждение ситуации могут перекрыть предпочтение.

База уже есть: WeaponClass, WorkingRange (shotgun 50 … sniper 300), balance-kind.

### #15B Ранг — поведенческий слой

Один framework, разный competence.

| Ранг | Поведение |
|------|-----------|
| Recruit | плохая оценка позиции, медленные решения, лишняя экспозиция, простое движение и CQB, может ошибаться |
| Soldier | базовое тактическое поведение |
| Corporal | лучше cover и позиция, понимает приказ |
| Veteran | cover, corner discipline, lean, CQB, смена поз, осмысленное движение, понимает оружие |
| Elite | быстрое понимание, минимум лишней экспозиции, позиционная игра, быстрый target transition, адаптация |

**Freeze.** Оружие задаёт тактическое пространство предпочтений. Разница рангов видна визуально и тактически, не только в числах навыков.

# ФАЗА IV. Группа и CQB — #16

Milestone **M4 — Tactical Group**: группа движется → входит → распределяется → поддерживает друг друга.

## #16A Group foundation

**Дизайн-док:** `Пехота_система_дизайн.md` **§6.9**.

```text
Group / Leader / Members / Formation / Spacing / Role / Sector
```

Стартовый набор: Column, Line, Wedge, Compressed Column. Позже CQB Stack.

Лидер задаёт direction / speed / objective / formation / task. Не Transform-follow. Каждый держит относительную тактическую позицию.

При контакте формация может стать: один cover, один fire, один move, один rear security.

**Freeze.** Группа — сущность. Индивидуальный AI не исчезает.

## #16B CQB

**Дизайн-док:** `Пехота_система_дизайн.md` **§6.9** (детали CQB — только design cycle этапа, §10).

Рамка принята, подробности **не утверждаем до design cycle этапа**:

```text
одно окно / дверь → stack → последовательный вход → каждый держит сектор
```

Не решаем сейчас: кто какой угол, кто первый, slice, когда стоп, кто rear, dead space, смена порядка. Вертикальный CQB / этажи — не этот этап.

Связка на этапе: Geometry + Rank + Weapon + Formation + Readiness + Lean.

# ФАЗА V. Адаптивный бой — #17–#23

**Дизайн-док:** `Пехота_система_дизайн.md` **§6.10** (все подэтапы фазы).

Milestone **M5 — Adaptive Combatant**: враг сопротивляется → AI меняет план. Игрок не может выучить «болванчиков на точках».

Threat, ImmediateThreat, Suppression, Wound **не смешивать**.

## #17 Under Fire

**Дизайн-док:** `Пехота_система_дизайн.md` **§6.10**.

```text
open → incoming fire → ImmediateThreat → identify direction → response
```

Варианты: мгновенный ответный огонь; укрытие → ответ; движение в укрытие → ответ. Решение зависит от rank / weapon / distance / cover / enemy / stance / mission.

Recruit: лишняя экспозиция / паника. Veteran: быстрое укрытие, контролируемый ответ.

## #17B Wound

**Дизайн-док:** `Пехота_система_дизайн.md` **§6.10**.

```text
Hit → evaluate → can fight? → cover / continue  или  emergency
```

Не медицинская симуляция. Ранение меняет поведение внутри той же машины.

## #18 Suppression

Влияет на risk tolerance, movement, exposure, reposition, readiness. Не заменяет ImmediateThreat и не заменяет Wound.

## #19 Reposition

```text
current position → враг знает место → ценность падает → alternatives → reposition?
```

Не менять позицию «потому что прошло 2 секунды». Нужен достаточный выигрыш.

## #20 Adaptive Attack

```text
ATTACK → RESISTANCE → ASSESS → CAN CONTINUE?
  yes → continue
  no  → change plan (reposition / suppress / alternative)
```

## #21 Flank / alternative route

```text
CENTER blocked → score LEFT / RIGHT → choose
Attack A → слишком сильный отпор → support fire → Flank B → Attack C
```

## #22 Fire & Maneuver

Если безопасно: fire → move → fire → move. Группа: один элемент стреляет, другой движется. Не прилипать к первой найденной позиции навсегда.

## #23 Grenades / special actions

После базового adaptive combat. Граната — ещё одно тактическое действие в том же ряду, что Shoot / Suppress / Move / Flank / Withdraw. Не отдельный AI.

```text
враг за укрытием → прямой огонь бесполезен → фланг дорогой → grenade viable → grenade → враг сдвинулся → engage
```

## #24 Commander

Решает Attack / Defend / Flank / Withdraw / Search / Hold / Capture.  
Не решает: солдату X повернуться на 13°, солдату Y сделать lean.

## #25 Squad tactics

Командир: Attack building.  
Группа: Element A assault, Element B support.  
Солдаты: A1 cover, A2 cover, A3 entry.  
Assault / Support / Cover / Reserve.

## #26 High-level planner

Только здесь Utility / HTN / GOAP / BT. Задача: **что группа должна попытаться сделать**. Не как конкретно стрелять из-за угла.

```text
Decision → Command → State → Execution
```

Не заменяет #5–#11 и не стреляет сам.
