## Правило работы

Каждый открытый этап проходит один цикл. После FREEZE следующий этап **не является поводом переделывать предыдущий**, пока тест прямо не доказал дефект закрытого слоя.

```text

  ↓
CONTRACT        ← контракт этапа не противоречит дизайн-доку §9–§10
  ↓
IMPLEMENTATION
  ↓
EDITMODE TESTS
  ↓
PLAY TESTS
  ↓
ARENA / SCENARIO TEST
  ↓
DIAGNOSTIC LOG
  ↓
FREEZE
```

**Перед открытием этапа #N:** прочитать соответствующий §6 в дизайн-доке и заполнить чеклист соответствия (таблица §11 дизайн-дока). **Перед FREEZE:** убедиться, что реализация не нарушает замороженные принципы §9 дизайн-дока.

Первый разрыв цепочки определяет виновный контур. Замороженные числа восприятия не ретюнятся ради «умного AI». Замороженный боевой контур не чинится ради укрытий или отряда.

## Замороженные принципы (не обсуждаем до своего этапа)

### Архитектура

Perception ≠ Combat ≠ Tactical AI. AI не жмёт спуск. `AI.EngageTarget` и `Combat.SelectedTarget` могут расходиться; #12 делает расхождение объяснимым и не сливает их.

### Оружие

Weapon Role = **предпочтение, не запрет**. Снайпер может штурмовать. LMG может идти вперёд. Автономно они предпочитают подходящие решения. Игровой приказ и миссия сильнее предпочтения.

### Укрытия

Динамические. **Нет** заранее расставленных CoverPoint_001. Солдат читает геометрию мира.

Два базовых класса: crouch cover и standing cover, плюс partial / corner.

Поиск укрытий:

```text
НЕ: каждый кадр сканировать все укрытия мира
А: NeedCover → локальный query → дешёвый фильтр → 3–10 лучших → дорогая оценка → cache
```

### Lean

Уже существует (Quick / Smooth / Deep). Подключается к тактике, не переписывается.

### Движение

NavMesh = как физически попасть из A в B.  
Tactical Movement = как сделать это с меньшим риском.  
В городе предпочтение вдоль зданий/укрытий, если ситуация опасная. Колонна **разрешена**.

### Формации

Column / Line / Wedge / Compressed Column. В бою формация может распасться на тактические роли (cover / fire / move / rear). Формация — не тюрьма.

### Ранг

Пять рангов меняют **поведение**, не только числа: Recruit, Soldier, Corporal, Veteran, Elite. Один AI + разный уровень компетенции. Не пять разных AI.

### Позы оружия

NotReady / LowReady / HighReady / HipFire / PointAim / Aiming. Боевой gate уже отличает стрелковые позы от нестрелковых.

### Readiness (#14B)

`NotReady / Patrol / LowReady / HighReady / PreAim / Aim` — отдельная ось, не поза и не G6. HostileVisible может сразу в Aim. Aim ≠ Fire.

### Адаптивность (позже обязательно)

resistance → reassessment → reposition → flank → alternate route.

### Under Fire / Wound

Ответ огнём или укрытие → ответный огонь. Ранение: cover → continue if capable.

| Ранг | Поведение |

## #17 Under Fire

**Дизайн-док:** `Пехота_система_дизайн.md` **§6.10**.

```text
open → incoming fire → ImmediateThreat → identify direction → response
```

Варианты: мгновенный ответный огонь; укрытие → ответ; движение в укрытие → ответ. Решение зависит от rank / weapon / distance / cover / enemy / stance / mission.

## #17B Wound

**Дизайн-док:** `Пехота_система_дизайн.md` **§6.10**.

```text
Hit → evaluate → can fight? → cover / continue  или  emergency
```

Не медицинская симуляция. Ранение меняет поведение внутри той же машины.

## #18 Suppression

Влияет на risk tolerance, movement, exposure, reposition, readiness. Не заменяет ImmediateThreat и не заменяет Wound.

## #19 Reposition

```text
current position → враг знает место → ценность падает → alternatives → reposition?
```

Не менять позицию «потому что прошло 2 секунды». Нужен достаточный выигрыш.

## #20 Adaptive Attack

```text
ATTACK → RESISTANCE → ASSESS → CAN CONTINUE?
  yes → continue
  no  → change plan (reposition / suppress / alternative)
```

## #21 Flank / alternative route

```text
CENTER blocked → score LEFT / RIGHT → choose
Attack A → слишком сильный отпор → support fire → Flank B → Attack C
```

## #22 Fire & Maneuver

Если безопасно: fire → move → fire → move. Группа: один элемент стреляет, другой движется. Не прилипать к первой найденной позиции навсегда.

## #23 Grenades / special actions

После базового adaptive combat. Граната — ещё одно тактическое действие в том же ряду, что Shoot / Suppress / Move / Flank / Withdraw. Не отдельный AI.

```text
враг за укрытием → прямой огонь бесполезен → фланг дорогой → grenade viable → grenade → враг сдвинулся → engage
```
