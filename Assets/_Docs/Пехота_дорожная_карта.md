## Замороженный закон

```text
Physical Visibility     может ли физически видеть
        ↓
       Q                насколько цель заметна (формула закрыта)
        ↓
   Attention            насколько взгляд уже туда (новый слой)
        ↓
DetectionProgress       скорость накопления
```

```text
увидел ≠ выбран ≠ можно целиться ≠ Fire ≠ выстрел
звук ≠ VisibleNow
доклад ≠ увидел
Attention ≠ новый FOV
Attention ≠ второй raycast
поворот юнита ≠ приказ GuardWindow
```

Hitscan пехоты: нет Observation дальше обзора → нет AimPoint → нет Fire.  
РПГ/MK19: нет зрения на точку → нельзя **назначить** цель. Снаряд после выстрела может лететь дальше обзора.
