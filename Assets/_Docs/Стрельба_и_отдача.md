Обозначения:

- `d` — дистанция до точки прицеливания, метры.
- `θ` — полуугол **intrinsic** конуса разброса, градусы (half-angle). **Не зависит от отдачи.**
- `Offset` — `Vector2` в градусах: `x` = yaw (вправо +, влево −), `y` = pitch вверх (+).
- `Kick` — дельта Offset за один успешный выстрел, градусы.
- `i` — номер уже сделанного выстрела с этим оружием в руках (`RecoilShotIndex` после выстрела). Для kick текущего выстрела берётся `i = RecoilShotIndex + 1`.
- `m` — общий множитель импульса (режим огня × патрон × модули × навык × состояние × поза).
- `×` — произведение независимых множителей (все стартуют с 1, если источника нет).
- `clamp(x, a, b)` — ограничение диапазона.
- `lerp(a, b, t)` — линейная интерполяция, `t` в 0…1.
- `MoveTowards(a, b, maxDelta)` — шаг от `a` к `b` не больше `maxDelta`.

На 100 м: **1° ≈ 1.75 м** (`d × tan(угол × π/180)`).

## 1. Модель: что система считает

### 1.1. Это не баллистика полёта

Пули как физического снаряда нет. Выстрел — **мгновенный луч** (hitscan) из дула до 500 м (дефолт дальности луча компонента). «Скорость патрона» нужна только для **упреждения** движущейся цели, не для времени полёта пули в мире.

### 1.2. Три канала — их нельзя смешивать

| Канал | Что это | Входит в формулу пули? | Для чего |
|-------|---------|------------------------|----------|
| **Accuracy** | Случайный конус вокруг *текущей* точки прицеливания | **Да**: `θ` | Intrinsic неточность, поза, навыки, неполный прицел |
| **Gameplay recoil** | Накопленный `RecoilOffset` (градусы yaw/pitch) | **Да**: поворот **центра** очереди. **Нет** в ширине `θ` | Соседние пули родственники; очередь уходит вверх и в сторону |
| **Visual recoil** | Punch руки/оружия + climb от `Offset.y` | **Нет** в направлении при выбранной цели. Косвенно может **задержать** следующий выстрел (гейт ствола) | Картинка |

Множители `VisualRecoilKickScale` и `ArmRecoilMultiplier` на оружии **не** меняют Offset и **не** меняют `θ`.

### 1.3. Куда летит луч при выбранной цели

```
направление_базы = normalize(точка_прицеливания + упреждение − origin)
направление      = поворот(направление_базы, Offset)   // yaw вокруг up, pitch вверх
направление      = случайный_конус(направление, θ)     // всегда, если θ > 0
```

**Не** «куда сейчас смотрит визуально дёрнутый ствол». Kick сдвигает точку старта луча (дуло чуть назад/вверх), но вектор при наличии цели считается **на точку прицеливания + Offset**.

Если цели нет — луч идёт вдоль `forward` дула (тогда visual kick уже влияет на направление). В бою цель обычно есть.

Упреждение:

```
время_полёта ≈ d / velocity_патрона          // velocity дефолт патрона 400 м/с
упреждение   = скорость_цели × время_полёта × TargetLeadFactor
TargetLeadFactor = 1.0 (можно 0…1.5)
```

Поворот Offset:

```
up    = world up, если ствол не смотрит почти вертикально; иначе world forward
right = cross(up, forward)
rotation = AngleAxis(Offset.x, up) * AngleAxis(−Offset.y, right)
направление = rotation * forward
```

Смещение точки попадания на дистанции `d` от одного только Offset (без конуса):

```
смещение_м ≈ d × tan(|Offset| × π/180)
```

### 1.4. Текущий выстрел не видит свой kick

Порядок внутри успешного выстрела фиксирован:

1. Проверки «можно ли стрелять» (ready, RPM, AimProgress, barrel-gate).
2. Расход патрона + постановка таймера RPM.
3. **Hitscan с текущим Offset** (kick от *прошлых* выстрелов, уже уменьшенный recovery).
4. Счётчик burst-очереди для гейта прицеливания увеличивается (это не recoil).
5. Событие `ShotFired`.
6. **Gameplay recoil: Offset += Kick** — только для *следующего* выстрела.
7. Visual punch от величины этого kick.

Пуля №1: Offset = (0, 0) + tiny cone. Пуля №2 уже сидит на kick первой.

Компенсации стрелка («тянет прицел обратно») **нет**. Навык RecoilControl только уменьшает kick и ускоряет recovery.

## 2. Порядок одного выстрела (тайминг)

Порядок скриптов на юните:

| executionOrder | Компонент | Роль |
|----------------|-----------|------|
| 55 | `UnitWeaponFireController` | Разрешение выстрела, расход патрона, `ShotFired` |
| 57 | `UnitWeaponHitscanShooting` | Луч: aim + Offset_текущий + cone(θ) |
| 58 | `UnitWeaponRecoilController` | Подписка на `ShotFired`: Offset += Kick |

```
кадр N, успешный выстрел
  TryConsumeShot
  Hitscan.ProcessSuccessfulShot     // луч: aim + Offset_текущий + cone(θ)
  RegisterBurstShotFired            // i_burst += 1  (гейт прицела, не recoil)
  ShotFired
    RecoilController                // Offset += Kick; RecoilShotIndex += 1
    UnitWeaponRecoil                // visual punch
    прочие подписчики
каждый кадр (в т.ч. между выстрелами и на паузе дисциплины)
  Offset = MoveTowards(Offset, 0, RecoilRecovery × множители × dt)
```

`StopFiring` (в том числе пауза fire discipline) **не обнуляет** gameplay Offset и `RecoilShotIndex`. Пауза = recovery. Сброс только при снятии оружия / `Clear()`. Visual punch при `StopFiring` сбрасывается (`ResetVisualKick`); climb на следующем кадре снова читает `Offset.y`.

Свойство `ResetRecoilOnStopFiring` на fire-контроллере по умолчанию true, но реализация сбрасывает **только visual kick**, не Offset.

## 3. Accuracy — маленький конус `θ`

### 3.1. Формула

```
raw = BaseShotDispersion
    × SpreadModifier_патрона
    × DistanceDispersion_оружия(d)
    × ∏ DistanceDispersion_модуля(d)     // оптика исключается в HipFire / PointAim / PreAim
    × Stance/PostureSpread
    × SkillSpread × TraitsSpread × ConditionSpread
    × IncompleteAimSpread(AimProgress, d)
    × PoseSpread                         // HipFire 2.5, PointAim 1.5, Aiming 1, × кривые дистанции
    × BaseSpreadToDegrees                // дефолт 0.35 на hitscan-компоненте

θ = clamp(raw, MinHalfAngle, MaxHalfAngle)
    MinHalfAngle = 0.04°
    MaxHalfAngle = 12°
```

В формуле **нет**:

- `RecoilOffset` / бывшего `P`
- `1 + P × RecoilSpreadScale`
- `AutoSpreadMultiplier` (старый 0.87 на авто)
- `AutoBurstSpreadMultiplierByShot` (кривая по номеру очереди)

Кривая `AutoBurstSpreadMultiplierByShot` на ассете ещё лежит, hitscan её не читает.

Случайный конус: точка внутри круга радиуса `tan(θ)` в плоскости, перпендикулярной направлению (уже повёрнутому на Offset).

Диаметр пятна на дистанции (только конус, без Offset):

```
диаметр_м = 2 × d × tan(θ × π/180)
```

### 3.2. Неполный прицел

Для 2-го и далее выстрела Burst/FullAuto `AimProgress` для разброса форсируется в 1. Первый выстрел серии может быть шире, если прицел не доведён.

Пороги прогресса: Snap 0.35, Quick 0.68, Full 1.00.

Базовый множитель от прогресса (до дистанции):

| AimProgress | множитель |
|-------------|-----------|
| 0.00 | 3.00 |
| 0.35 (Snap) | 2.20 |
| 0.68 (Quick) | 1.45 |
| 0.85 | 1.15 |
| 1.00 | 1.00 |

Дистанция масштабирует **избыток** (то, что больше 1):

```
если base ≤ 1: результат = 1
иначе: 1 + (base − 1) × scale(d)

scale: d≤10 → 0.60; 25 → 1.00; 50 → 1.25; ≥100 → 1.50
(внутри формулы d сначала умножается на 0.2: «25 м» в таблице scale — это 125 м реальных)
```

### 3.3. Типичный порядок `θ` (M4, Aiming, полный прицел, 100 м)

`BaseShotDispersion ≈ 0.55…0.92` (зависит от ассета; M4 ModA1 на снимке **0.92**), `BaseSpreadToDegrees = 0.35` → raw порядка **десятых долей градуса** до дистанции/позы. Это **не** бывшие 2–5° от накопленного `P`. Очередь больше не «размазывается облаком»; она **смещается целиком**.

## 4. Gameplay recoil — RecoilOffset

### 4.1. Состояние (пока оружие в руках)

Хранится в transient-состоянии экипированного оружия:

```
Offset        Vector2   градусы, x = yaw, y = pitch вверх     // RecoilOffset
PatternValue  float     сглаженный горизонтальный сигнал, примерно −1…1
ShotIndex     int       сколько успешных выстрелов сделано с этим экземпляром в руках
```

Страховочный кап на контроллере: `|Offset| ≤ 12°` (`MaxRecoilOffsetDegrees`, константа математики `DefaultMaxOffsetDegrees = 12`).

### 4.2. Kick (только успешный выстрел)

`i = ShotIndex + 1`

Константы математики:

| Константа | Значение |
|-----------|----------|
| PatternSmooth | 0.35 |
| VerticalVariationMin / Max | 0.85 / 1.15 |
| MaxHorizontalStepScale | 1.25 |
| MaxVerticalStepScale | 1.20 |
| PatternFreq1 / Weight1 | 0.73 / 0.65 |
| PatternFreq2 / Weight2 | 1.31 / 0.35 |
| PatternSeed2Scale | 1.7 |
| RecoveryWhileFiringForPrediction | 0.70 |

```
verticalVariation = lerp(0.85, 1.15, Hash01(seed, i, 0))

rawPattern = sin(seed + i × 0.73) × 0.65
           + sin(seed × 1.7 + i × 1.31) × 0.35

pattern    = lerp(PatternValue, rawPattern, 0.35)

m = fireModeMult
  × ammo.RecoilModifier
  × ∏ attachment.GetRecoilModifier(fireMode)
  × RecoilControl_added          // навык, типично 0.8…1.2
  × traits × condition × posture

deltaY = VerticalRecoil × verticalVariation × m
deltaX = HorizontalRecoil × pattern × m

deltaY = clamp(deltaY, 0, VerticalRecoil × 1.20 × m)
deltaX = clamp(deltaX, −HorizontalRecoil × 1.25 × m, +HorizontalRecoil × 1.25 × m)

Offset += (deltaX, deltaY)
если |Offset| > 12°: Offset *= 12 / |Offset|

PatternValue = pattern
ShotIndex   += 1

visualImpulse = deltaY / VerticalRecoil     // ≈ verticalVariation × m; для картинки, не для пули
```

`fireModeMult`:

| Режим | Поле оружия | Типичное значение на снимке |
|-------|-------------|-----------------------------|
| SemiAuto | `SemiAutoRecoilMultiplier` | 0.74…1.05 |
| FullAuto / Burst / Auto | `AutoRecoilMultiplier` | 0.96…1.55 |

```
seed = RecoilPatternSeed_оружия + (instanceId & 1023) × 0.017
```

Два одинаковых автомата в руках разных юнитов рисуют родственников, но не один и тот же синус. Сто очередей одного ствола остаются похожими (`ShotIndex` и seed экземпляра стабильны, пока оружие не сняли).

`sin` считается **только в момент выстрела**, не каждый кадр.

Вертикальный kick **не бывает отрицательным**. Вниз очередь возвращается только recovery.

### 4.3. Recovery (каждый кадр)

```
rate = RecoilRecoveryPerSecond          // °/с на ассете оружия
     × (IsFiring ? 0.7 : 1.0)           // RecoveryWhileFiringMultiplier на контроллере
     × (не ready ? 1.2 : 1.0)           // RecoveryWhenNotReadyMultiplier
     × skill_recovery × traits_recovery × condition_recovery

Offset = MoveTowards(Offset, (0,0), rate × dt)
```

Единица — **градусы в секунду**, не старые единицы `P`. Старые 3.5–5 на ассетах **нельзя** читать как °/с: при kick 0.12° и интервале 0.1 с recovery 3.5°/с съест 0.35° за интервал, и очередь не поднимется. Поэтому на ассетах сейчас 0.40…0.85 °/с.

Пока курок зажат, recovery медленнее (×0.7), чтобы нетто kick на 600 RPM оставался положительным.

**Стойка, поза и спринт входят и в kick, и в recovery** через `WeaponRecoilContext` (`StanceKickMultiplier` / `StanceRecoveryMultiplier`, `PoseKickMultiplier` / `PoseRecoveryMultiplier`). Спринт — отдельная строка стойки (θ ×2.50, kick ×1.60, recovery ×0.50), не walk ×1.25. Турель: пехотные множители = 1. Таблицы — §13 / §14.2–14.3.

### 4.4. Поля оружия, которые реально крутят отдачу

| Поле ассета (C#) | Смысл | Единица | Legacy? |
|------------------|--------|---------|---------|
| `FireRateRpm` | интервал выстрела = 60/RPM | выстр/мин | нет |
| `BaseShotDispersion` | база конуса **до** `BaseSpreadToDegrees` | множитель | не этап-1 recoil |
| `VerticalRecoil` | подъём за выстрел до множителей | ° | живое |
| `HorizontalRecoil` | боковой kick до паттерна | ° | живое |
| `RecoilRecoveryPerSecond` | возврат Offset | °/с | живое |
| `SemiAutoRecoilMultiplier` | × kick в Semi | безразм. | живое |
| `AutoRecoilMultiplier` | × kick в FullAuto/Burst/Auto | безразм. | живое |
| `RecoilPatternSeed` | фаза синуса (+ хэш экземпляра) | безразм. | живое |
| `BurstRounds` / `BurstPauseSeconds` | длина и пауза режима Burst | шт / с | живые для Burst, не Offset |
| `VisualRecoilKickScale` | только картинка punch | × | не пуля |
| `ArmRecoilMultiplier` | только картинка руки | × | не пуля |
| `RecoilPerShot` | старый безразмерный P | — | **не читается gameplay** |

Живые числа по стволам — §17.

Модули и патроны: `RecoilModifier` — множитель **kick**, не конуса. `SpreadModifier` патрона — только `θ`.

## 5. Выбор режима Auto

После удаления отдачи из `θ` нельзя оценивать FullAuto по одному только конусу: intrinsic `θ` маленький, и ИИ решил бы, что авто точно на любой дистанции.

Селектор считает **групповой** диаметр на представительном выстреле:

```
представитель: FullAuto → выстрел 5, Burst → выстрел 3, Semi → 1

predicted = |Offset| после (представитель − 1) kick'ов
            с recovery ×0.7 между ними на RPM оружия
            (без навыка/позы, с модулями)

groupθ        = θ_intrinsic + predicted
groupDiameter = 2 × d × tan(groupθ × π/180)

приемлемо, если groupDiameter ≤ 0.60 / √0.60 ≈ 0.775 м
```

Порядок кандидатов при `FireMode = Auto`: FullAuto → Burst → SemiAuto. При `AimMode = Auto`: Snap → Quick → Full.

Fire discipline по-прежнему режет длину очереди и ставит паузы; на паузе Offset **не** сбрасывается, только восстанавливается.

Предсказание в коде: `WeaponRecoilMath.PredictOffsetBeforeShot` / `PredictOffsetAfterShots` / `PredictOffsetAfterBurstAndPause` через `WeaponRecoilContext`. Auto-селектор передаёт stance/pose kick+recovery и instance hash. Формула диаметра группы **не менялась:** 0.60 / √0.60 ≈ 0.775 м.

**Не закрыто:** фактические дистанции переключения M4/AK в Play (14.6 / N9). Planner **уже** режет серию по predicted \|Offset\| vs 0.60 м × 0.85 (14.8 закрыт кодом).

## 6. Кто разрешает выстрел

Цепочка `UnitWeaponFireController`:

1. Оружие в допустимой позе (Aiming / HipFire / PointAim; турель — исключение). HighReady/NotReady обычно запрещены.
2. Юнит не busy: смена стойки, reload, бросок, РПГ, стабилизация, proximity relax.
3. Ready (если включено требование).
4. Есть цель / линия огня (отдельная проверка LoF с ретраем).
5. RPM: `NextAllowedShotTime`.
6. Порог `AimProgress` (для авто/burst — в основном 1-й выстрел волны; со 2-го прогресс для разброса форсируется в 1, но гейт первого выстрела жив).
7. **Barrel-alignment gate:** угол между `fireOrigin.forward` и `WeaponRecoilMath.ApplyOffsetToDirection(toTarget, RecoilOffset)` ≤ допуск позы×стойки×движения. Честный Offset не глушит очередь сам по себе. Visual punch + climb от Offset.y могут **отложить** выстрел, только если дуло уехало дальше допуска.

Счётчик `ConsecutiveBurstShotsFired` — для гейта прицела и длины Burst. Он **сбрасывается** на `StopFiring`. `RecoilShotIndex` при этом **не** сбрасывается.

Гейт ствола **сравнивает визуальный forward дула с aim+Offset (вес 1)**, не с геометрической точкой цели. SIM_PLAY N8 записан 2026-08-23 19:04: remaining 0.000°, index=3, M4/M249/PKM wouldFire=True — §20.1.1.

Допуски гейта (градусы, дефолты компонента):

| Поза × стойка × движение | допуск ° |
|--------------------------|----------|
| Aiming стоит | 3 |
| Aiming идёт | 8 |
| Aiming сидя/лёжа стоит / идёт | 9 / 9 |
| PointAim стоит / идёт | 5 / 10 |
| PointAim сидя стоит / идёт | 7 / 11 |
| HipFire стоит / идёт | 12 / 16 |
| HipFire сидя стоит / идёт | 14 / 18 |

«Движение» для гейта = move intent нав-драйвера (или click-to-move), не фактическая скорость. Тащит раненого → колонка «стоит».

Пропуск гейта: цикл затвора (патронник пуст, магазин есть, патроны в магазине).

## 7. Паузы дисциплины и смена оружия

| Событие | Gameplay Offset | RecoilShotIndex | Visual punch |
|---------|-----------------|-----------------|--------------|
| Пауза очереди / `StopFiring` | recovery идёт дальше | сохраняется | snap в 0 |
| Смена магазина, пока оружие в руках | сохраняется | сохраняется | свой цикл |
| Снятие оружия / `Clear()` | `(0,0)` | 0 | 0 |

Короткая пауза «2–3 выстрела — пауза — ещё 2» **не** начинает очередь с нуля: ствол уже чуть поднят.

Пример: recovery while-not-firing 0.70 °/с, пауза 0.4 с → снимает 0.28°.  
M4 после 3 выстрелов (~0.25° накопления) почти обнуляется.  
ПКМ/M249 после 10 выстрелов (~1°+) почти не чувствует паузу.

Именно поэтому 14.1 нужно выбрать **до** баланса длины очереди.

## 8. Визуал (не формула пули)

Punch (за выстрел):

```
visualImpulse ≈ deltaY / VerticalRecoil     // ≈ verticalVariation × m
impulse       = visualImpulse × VisualRecoilKickScale
punchPitch    = impulse × ShotPitch (дефолт компонента ~2.5°)
+ translation back/up
```

Climb (каждый кадр):

```
climbPitch = Offset.y × VisualOffsetScale × VisualRecoilKickScale
```

Кривая `PitchCurve(P)` на визуальном компоненте больше не кормит climb. Поле оставлено на префабе.

Hitscan **не** берёт visual punch в направление луча, если есть цель.

A10 **не** закрывается калибровкой punch/back/up. Если картинка мешает гейту — чинить гейт (14.5), не hitscan.

## 9. Числовой пример: M4 FullAuto, 600 RPM, нейтральные множители

Допущения: `m = AutoRecoilMultiplier = 1.22`, патрон/модули/навык/поза = 1, `VerticalRecoil = 0.09`, `HorizontalRecoil = 0.035`, recovery 0.70 °/с, while-firing ×0.7 → 0.49 °/с. Интервал `60/600 = 0.10 с`. Recovery между выстрелами ≈ `0.049°`.

Вариация и паттерн зависят от seed; ниже порядок величины при `verticalVariation = 1.0`, `pattern ≈ +0.4`.

```
kickY ≈ 0.09 × 1.0 × 1.22 = 0.110°
kickX ≈ 0.035 × 0.4 × 1.22 = 0.017°
нетто за интервал ≈ 0.110 − 0.049 = 0.061° вверх
```

| Выстрел | Offset до луча (примерно) | Что делает пуля | Offset после kick |
|---------|---------------------------|-----------------|-------------------|
| 1 | (0, 0) | в точку прицеливания + tiny cone | ≈ (0.02, 0.11) |
| 2 | ≈ (0.02, 0.06) после recovery | чуть выше и в сторону | ≈ (0.04, 0.17) |
| 5 | ≈ 0.24° вверх | группа уже выше центра цели | растёт дальше |
| пауза 0.4 с | recovery 0.70×0.4 = 0.28° к нулю | следующая пуля не с нуля, если накопление больше | не snap |

На 100 м `0.24°` ≈ 0.42 м выше точки прицеливания. Конус `θ ≈ 0.2°` даёт пятно диаметра ≈ 0.70 м **вокруг этого смещённого центра**, а не облако вокруг исходного прицела.

Старая модель на 5-м выстреле раздувала `θ` через `P × 0.22` до нескольких градусов — соседние пули были независимыми семплами огромного конуса. Этого больше нет.

## 10. Что крутить

| Хочу | Крутить | Не крутить |
|------|---------|------------|
| Круче/мягче подъём очереди | `VerticalRecoil`, `AutoRecoilMultiplier` | `BaseShotDispersion` |
| Шире/уже «змейка» в стороны | `HorizontalRecoil`, `RecoilPatternSeed` | конус `θ` |
| Быстрее опускается после паузы | `RecoilRecoveryPerSecond` **или** правило 14.1 | `StopFiring` как snap Offset |
| Кучнее первая пуля | `BaseShotDispersion`, поза, прицел | recoil-поля |
| ИИ реже берёт FullAuto на дистанции | Vertical/recovery (через predicted Offset) или порог 0.775 м | надеяться, что конус «сам раздует авто» |
| Сильнее картинка kick | `VisualRecoilKickScale`, `ShotPitch` | gameplay Offset |
| Меньше отдача у бойца | RecoilControl (kick вниз, recovery вверх) | FullAuto control-blend 5…10 — его нет |

Если очередь «не поднимается»: recovery слишком большой относительно `VerticalRecoil × RPM`. Если улетает в зенит: мало recovery или велик `VerticalRecoil` (кап 12° всё равно поймает).

Стартовые ассеты — калибровочная точка, не финал. См. §17.

## 11. Чего больше нет

- `EquippedWeaponTransientState.RecoilPenalty` / `SetRecoilPenalty`
- `θ × (1 + P × RecoilSpreadScale)` (hitscan 0.22 и контроллер 0.15)
- процедурный паттерн `P × 0.09°` только для авто с `i ≥ 2`
- FullAuto «control blend» выстрелы 5…10 (вертикаль режется, yaw растёт)
- snap gameplay recoil на `StopFiring`
- `AutoSpreadMultiplier` и `GetAutoBurstSpreadMultiplier` в формуле пули
- компенсация прицела стрелком (ShooterControl) — отдельный будущий слой
- rigidbody / пружины / таблица 30 точек паттерна
- смешивание visual punch в hitscan при выбранной цели

Навык по-прежнему вешается на kick (`GetRecoilAddedMultiplier`) и recovery (`GetRecoilRecoveryMultiplier`). Отдельной ветки «после 5-го выстрела вертикаль в горизонталь» нет.

## 12. Полный каталог: что влияет на точность и отдачу

Если источника нет на юните, множитель = 1 (кроме позы: fallback §13).

```
θ     = intrinsic-конус          // точность, случайный семпл вокруг центра
центр = aim + lead + Offset      // отдача, детерминированный поворот
пуля  = случайная точка в конусе θ вокруг центра
```

### 12.1. Точность — формула `θ` целиком

```
raw = BaseShotDispersion
    × ammo.SpreadModifier
    × GetDistanceDispersionMultiplier(d)
    × ∏ attachment.GetDistanceDispersion(d)   // оптика ИСКЛЮЧАЕТСЯ в HipFire / PointAim / PreAim
    × postureSpread                           // §13: стойка×движение ИЛИ спринт
    × skill.Marksmanship                      // 0 → ×1.25, 50 → ×1.00, 100 → ×0.75
    × traits.MarksmanshipModifier             // max(0.01, 1 − modifier)
    × condition.dispersion                    // раны/боль/подавление/усталость ready
    × incompleteAim(progress, d)              // только 1-й выстрел Burst/FullAuto
    × poseSpread                              // HipFire 2.5 / PointAim 1.5 / PreAim 1.75 / Aiming 1
    × poseDistanceCurve(pose, d)
    × laserPointAimSpread(d)                  // только PointAim, только ЛЦУ
    × BaseSpreadToDegrees                     // 0.35

θ = clamp(raw, 0.04°, 12°)
диаметр_пятна_м = 2 × d × tan(θ × π/180)
```

**Не входит в `θ`:** VerticalRecoil, HorizontalRecoil, Offset, RecoilControl, RecoilModifier патрона/модуля, Semi/Auto recoil multipliers, recovery, stance recoil multipliers.

### 12.2. Навык (шкала 0…100, нейтраль 50 = ×1.0)

| Навык | Метод | Канал | 0 | 50 | 100 |
|-------|--------|-------|---|----|-----|
| Marksmanship | `GetDispersionMultiplier()` | `θ` | ×1.25 | ×1.00 | ×0.75 |
| WeaponHandling | `GetAimTimeMultiplier()` | время прицела, не пуля | ×1.25 | ×1.00 | ×0.75 |
| RecoilControl | `GetRecoilAddedMultiplier()` | kick `m` | ×1.20 | ×1.00 | ×0.80 |
| RecoilControl | `GetRecoilRecoveryMultiplier()` | recovery °/с | ×0.80 | ×1.00 | ×1.20 |

Интерполяция: lerp(худший, лучший, skill/100).

### 12.3. Индивидуальные черты

`MarksmanshipModifier` / `RecoilControlModifier` — обычно маленькие числа вроде 0.05.

```
dispersion     = max(0.01, 1 − MarksmanshipModifier)
recoilKick     = max(0.01, 1 − RecoilControlModifier)
recoilRecovery = max(0.01, 1 + RecoilControlModifier)
```

Черта «лучше контроль» одновременно уменьшает kick и ускоряет recovery.

### 12.4. Состояние (раны, боль, подавление, усталость рук)

Флаги по умолчанию выключены. Когда включены, **перемножаются**:

| Флаг | `θ` | kick | recovery |
|------|-----|------|----------|
| Руки ранены | ×1.35 | ×1.25 | ×0.85 |
| Сильная боль | ×1.20 | ×1.10 | ×0.90 |
| Подавление | ×1.15 | — | — |
| Ready-стамина исчерпана | ×1.20 | ×1.50 | — |
| Ноги ранены | не на `θ`; ×1.20 к **времени прицела только на ходу** | — | — |

### 12.5. Патрон

| Поле | Куда |
|------|------|
| `SpreadModifier` | только `θ` |
| `RecoilModifier` | только kick `m` |
| `Velocity` | только упреждение |
| `ProjectileCount` / дробовой паттерн | несколько лучей вокруг **того же** центра Offset |

### 12.6. Модули

```
kick:   m *= RecoilModifier × (AutoRecoilModifier если FullAuto/Burst, иначе SemiAutoRecoilModifier)
θ:      только дистанционные кривые модуля; оптика не работает в HipFire/PointAim/PreAim
PointAim + ЛЦУ: отдельный EvaluateLaserPointAimSpread(d)
время прицела: AimTimeModifier × кривая (не пуля, но влияет, успеет ли AimProgress дойти до порога)
```

Компенсатор/ДТК с числами 0.92 / 1.08 крутят **градусный kick**. При VerticalRecoil 0.09 это ~0.007° за выстрел — на 600 RPM почти не видно. Старые 0.90 писались против `P≈0.5`. **Переработка: 14.4.**

### 12.7. Отдача — формула kick целиком

```
m = fireModeMult
  × ammo.RecoilModifier
  × ∏ attachment.GetRecoilModifier(mode)
  × RecoilControl_added
  × traits_recoil
  × condition_recoil
  × stanceCombat.recoil                 // §13, таблица стойка×движение

Kick.y = clamp(VerticalRecoil × variation(0.85…1.15) × m,  0,  VerticalRecoil × 1.20 × m)
Kick.x = clamp(HorizontalRecoil × pattern(−1…1) × m,  ±HorizontalRecoil × 1.25 × m)

Offset += Kick
|Offset| ≤ 12°
```

Recovery каждый кадр — §4.3.

### 12.8. Что влияет косвенно (не в формуле пули)

| Механика | Эффект |
|----------|--------|
| AimProgress / дисциплина | может запретить 1-й выстрел серии |
| Barrel-alignment gate | visual ствол vs цель; punch + climb могут задержать выстрел |
| RPM / NextAllowedShotTime | recovery между пулями = rate × (60/RPM) |
| Пауза дисциплины → StopFiring | visual punch snap; Offset только recovery |
| Смена оружия / Clear() | Offset = 0, ShotIndex = 0 |
| Выбор Auto fire/aim | сравнивает `2×d×tan(θ + \|predicted Offset\|)` с 0.775 м |

## 13. Позы, стойка, движение — что происходит сейчас

Три ортогональных состояния:

1. **Поза оружия** (HipFire / PointAim / Aiming / PreAim / HighReady / NotReady).
2. **Стойка тела** (Standing / Crouch / Prone).
3. **Движение** (стоит / есть move intent / спринт).

Они умножаются отдельно. Пример: HipFire + шаг стоя = poseSpread 2.5 × walkStandingSpread 1.25 × HipFire distance curve.

### 13.1. Поза оружия → `θ`, kick и recovery

Живые числа: `WeaponPoseCombatModifiers`.

| Поза | θ × | kick × | recovery × | кривая точности по дистанции (выжимка) |
|------|-----|--------|------------|----------------------------------------|
| Aiming | 1.00 | 1.00 | 1.00 | 25 м ×1.00; 100 м ×1.05; 500 м ×1.15 |
| PointAim | 1.50 | 1.10 | 0.90 | 25 м ×1.20; 100 м ×1.90; 500 м ×7.00 + ЛЦУ |
| PreAim | 1.75 | 1.15 | 0.85 | как Aiming-кривая |
| HipFire / HipFireWalk / HipFireCrouchWalk | 2.50 | 1.35 | 0.70 | 5 м ×1.10; 10 м ×1.50; 25 м ×3.50; 100 м ×10 |
| HighReady / NotReady / LowReady | 1.00 (default) | 1.00 | 1.00 | выстрел обычно запрещён порогом прицела |

HipFire на 25 м: `θ` уже в ~3.5 раза шире Aiming **до** стойки. Калибровалось под старый огромный конус с `P`. Под маленьким intrinsic `θ` HipFire 25 м: 0.2 × 2.5 × 3.5 ≈ 1.75° полуугол ≈ 3 м диаметр на 50 м. **Проверить в Play.** Карточка 14.3 / N14.

Kick **зависит** от позы: HipFire ×1.35 vs Aiming ×1.00. RecoilContract проверяет, что |Offset| после 5 выстрелов у HipFire больше, чем у Aiming.

### 13.2. Стойка × движение → `θ`, kick и recovery

Если на юните есть `UnitStanceCombatModifiers` (на пехотном префабе есть), hitscan **не** использует свои поля Standing/Crouch/Prone/Moving как истину. Берётся эта таблица. Турель (`IsOperatingVehicleTurret`) пропускает пехотные множители (все = 1).

| Состояние | `θ` | kick | recovery | время прицела |
|-----------|-----|------|----------|---------------|
| Стоя на месте | ×1.00 | ×1.00 | ×1.00 | ×1.00 |
| Сидя на месте (лёжа = эти же числа) | ×0.92 | ×0.95 | ×1.10 | ×1.10 |
| Шаг стоя | ×1.25 | ×1.25 | ×0.85 | ×1.55 |
| Шаг сидя | ×1.12 | ×1.10 | ×0.95 | ×1.30 |
| Спринт | ×2.50 | ×1.60 | ×0.50 | ×1.80 |
| Тащит раненого | ×1.04 | ×1.05 | ×0.90 | ×1.10 |

**Лёжа отключена:** locomotion Prone не калибруется. Crouch и Prone читают числа сидя. На hitscan ещё висят старые поля Crouch 0.90 / Prone 0.75 / Moving 1.35 — живы только если компонента стойки нет (N3).

Движение = «есть move intent у нав-драйвера», не фактическая скорость. Юнит, который «хочет идти», но стоит в толпе, уже получает walk-штраф. Спринт проверяется после «тащит», до шага.

Методы: `GetSpreadMultiplier()`, `GetAimTimeMultiplier()`, `GetRecoilAddedMultiplier()`, `GetRecoilRecoveryMultiplier()`.

### 13.3. Что чувствует стрелок в типичных сценах

**Aiming, стоя, очередь M4, 50 м.**  
Конус крошечный. Очередь уходит вверх цельным следом (`Offset.y` растёт ~0.06° нетто за выстрел). Попадания кучные, но выше точки прицеливания. Компенсации прицела нет.

**HipFire, шаг, 15 м.**  
Конус: 2.5 × ~2.2 (кривая HipFire) × 1.25 (шаг) ≈ ×6.9 к базе. Kick HipFire ×1.35 поверх шага ×1.25. Группа широкая **и** её центр ползёт быстрее Aiming.

**Пауза дисциплины 0.4 с после 3 выстрелов.**  
Пауза **A**: Offset за 0.4 с возвращается на полной скорости recovery (while-firing ×0.7 снимается, потому что команды огня нет). Если накопилось 0.25°, остаток ~0. Если LMG настрелял 2°, остаток ~1.7° — очередь продолжает с поднятого ствола. **Дисциплина не сбрасывает отдачу.**

**Спринт-огонь (если гейт пускает).**  
Строка таблицы: θ ×2.50, kick ×1.60, recovery ×0.50. Не отдельный обход hitscan.

### 13.4. Визуал vs пуля в позах

Climb = `Offset.y × VisualOffsetScale × VisualRecoilKickScale`. Punch — импульс за выстрел.

После очереди Offset.y может быть 0.5–3°. Climb держит ствол выше точки прицеливания. Punch snap на StopFiring, climb **нет**. Гейт сравнивает ствол с aim+Offset (вес 1), а не с геометрической точкой цели — честный Offset не глушит огонь сам по себе. На Aiming допуск 3°. SIM_PLAY после паузы — §20.1.1 (N8).

### 16.1. Математика (без MonoBehaviour)

**`WeaponRecoilKick`** (readonly struct)

| Поле | Тип | Смысл |
|------|-----|--------|

**`WeaponRecoilMath`** (static)

Константы — §4.2.

| Метод | Что делает |
|-------|------------|
| `ResolveFireModeMultiplier(weapon, fireMode)` | Semi → `SemiAutoRecoilMultiplier`, FullAuto/Burst/Auto → `AutoRecoilMultiplier` |
| `ComposeImpulseMultiplier(weapon, fireMode, ammo, attachmentProduct, skill, traits, condition, posture)` | собирает `m` |
| `CombinePatternSeed(weaponSeed, instanceHash)` | `seed + (hash & 1023) × 0.017` |
| `ComputeKick(weapon, seed, shotIndex, previousPattern, impulseMultiplier)` | Kick + новый pattern + visualImpulse. `shotIndex` 1-based |
| `ApplyKick(offset, delta, maxOffsetDegrees)` | сложение + кап по магнитуде |
| `Recover(offset, degreesPerSecond, deltaTime)` | `MoveTowards` к нулю |
| `ApplyOffsetToDirection(baseDirection, offsetDegrees)` | поворот луча |
| `PredictOffsetBeforeShot(weapon, attachments, fireMode, shotIndex)` | Offset **до** выстрела `shotIndex` (1-based), recovery while-firing ×0.7, без навыка/позы/патрона |
| `PredictOffsetAfterShots(..., shotCount, recoveryWhileFiring)` | Offset сразу после `shotCount` выстрелов (= до выстрела shotCount+1) |
| `PredictOffsetAfterBurstAndPause(..., burstShotCount, pauseSeconds, ...)` | серия + полная recovery на паузе |
| `OffsetToDisplacementMeters(offsetMagnitudeDegrees, distanceMeters)` | `d × tan(°)` |
| `SpreadDiameterMeters(distanceMeters, halfAngleDegrees)` | `2 × d × tan(θ)` |

Есть парные `*Magnitude*` методы — возвращают `.magnitude`.

Перегрузки `in WeaponRecoilContext`: тот же Predict/ComputeKick/ComposeImpulse/ComposeRecovery. Контекст собирает модули V/H/Recovery, навык, стойку, позу, instance hash, кап 12°, while-firing ×0.7, not-ready ×1.2.

### 16.6. Что A10 имеет право менять

Разрешено:

- правило паузы (fire controller / recoil controller / discipline);
- таблица стойки (`UnitStanceCombatModifiers`) и позы (hitscan pose spread + новые kick/recovery рычаги);
- удаление дублей hitscan Standing/Crouch/Prone/Moving;
- barrel-gate (сравнение с aim+Offset и/или допуски);
- числа `WeaponDefinition` Vertical/Horizontal/Recovery/Semi/Auto/Seed;
- RecoilModifier модулей (или новые поля);
- planner: predicted |Offset| vs размер цели;
- турельная таблица (без пехотных поз);
- дробовой паттерн только если он не сидит на Offset.

Запрещено без отдельного решения: hitscan-смешивание punch, возврат RecoilPenalty, Q/зрение/AI, ShooterControl, visual back-first как замена Offset.

- MeanHit / PLAY группа = среднее попаданий 1..N (конус вокруг текущего Offset на каждом выстреле). Обычно **ниже** |Offset| after N.
- Spread = макс. попарное расстояние вокруг центра группы, не вокруг aim.
- Shot1 RecoilOffset = 0: любое |группа| — это **конус θ**, не kick.
- Remaining ≈ 0 после паузы при RecoilShotIndex=3 — **drain recovery**, не snap `StopFiring`.

#### Генератор loadout — как не взорвать число тестов

1. Слоты с `WeaponDefinition.AttachmentSlots`.

3. На слот: {пусто} ∪ кандидаты слота.
