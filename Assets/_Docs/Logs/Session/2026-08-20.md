## Коротко

За ночь закрыт AI-слой до RoE включительно. Юнит умеет:

1. воспринимать (`AIPerceptionFrame`)
2. иметь задачу (`UnitAIState`)
3. решать, можно ли применять силу (`UseOfForceLevel` → `ForcePermission`)
4. отдать G6 решение Track / Aim / Fire, если сила разрешена

**Ещё не умеет:** сам ходить по задаче и сам жать на курок как execution. Это следующий слой.

Инвариант не менять:

```text
physical evidence → confidence → knowledge → decision
```

Зрение ≠ приказы ≠ поиск ≠ тактика. Perception 500 м ≠ engage 18 м.

В **обычном Play** справа сверху две кнопки:

- **Игрок (сила)** — цикл RoE всех `UnitTeamId.Player`
- **Враг (сила)** — цикл всех `UnitTeamId.Enemy`

Число в скобках — сколько юнитов стороны в сцене.

### 1) Navigation (первый кандидат)

Смысл: юнит **выполняет** уже выбранную задачу ногами.

| State | Что должен делать нав |
|-------|------------------------|
| Idle | стоять / не начинать сам |
| Defense | держаться якоря / сектора |
| Attack | идти к destination / цели |
| Search | идти к `SearchPosition` = LastKnown, не двигать Memory |
| Retreat | идти на destination |
| Flee | уходить по escape |

Подсказки:

- Драйвер уже есть: `UnitNavLocomotionDriver`. Не писать второй click-to-move.
- Нав **читает** State + Context. Нав **не** меняет `UnitAIState` (это только `UnitAIController.TryApplyCommand`).
- Search не вызывает decay и не переписывает `LastKnownPosition` / `LastSeenConfidence`.
- Не вести юнита на 500 м «потому что видит». Engage range по-прежнему **18 м**.
- Не звать `TargetSelector` из нав-слоя «чтобы выбрать куда идти». Точка уже в context / LastKnown.
- Play-дым: Defense держит точку; Attack доходит; Search идёт на LastKnown, пока память полезна; stale → resume Defense/Attack как в AI-1.10.

1. **«Плохо ищет / плохо стреляет»** — сначала слой: зрение уже закрыто. Смотреть State, RoE, G6, нав, оружие.
2. **Hostile на 15 м + SelfDefense** — Threat будет High, но сила всё равно запрещена без `ImmediateThreat`.
3. **Две кнопки RoE** после клика вешают `UnitAIController` → G6 начинает фильтровать Fire. До первого клика G6 как раньше.
4. **Мир Team ≠ Perception.** Affiliation / Relationship / Identity не брать из `UnitTeam` цели.
5. **Selected ≠ Engageable ≠ Fire ≠ Allowed.** Все четыре разные.
6. **Обычный Play vs меню тестов.** Кнопки RoE видны в обычном Play. Меню AI Use of Force само выходит из Play после отчёта.
