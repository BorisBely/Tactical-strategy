# План: ПКМ-меню на маркере маршрута + гранатомёт (H)

## Структура меню

```
ПКМ по сегменту маршрута
├── Перезарядка          — выполняет перезарядку оружия на точке
├── Граната ▸            — подменю с типами гранат → отложенный бросок
├── Гранатомёт ▸         — RPG из сумки (как H); при >1 — выбор экземпляра
├── Режим движения ▸     — подменю: Бег / Шаг / Присед → смена стойки/темпа
├── Поворот ▸            — подменю: Поворот / Пост.поворот / В точку
├── Пополнить магазины   — зарядка всех магазинов + перезарядка оружия
└── Остановка            — точка ожидания (wait point), как по Alt
```

Пункт «Гранатомёт» скрывать, если у юнита нет ракетницы в сумке.

## Ключевое правило: срабатывание только по достижению точки

Все ордера на маршруте **не выполняются** в момент клика по меню. Меню только создаёт отложенный ордер + маркер.

Активация — по образцу facing arrows:
`HasReachedRouteOrderAnchor` (planar distance ≤ `c_FacingArrowActivationReachRadius` ≈ 0.35 m).

При достижении: Stop → действие → Resume.
