========================================
 КОНВЕРТАЦИЯ МАТЕРИАЛОВ В URP
========================================

Проблема: материалы используют Built-in шейдеры (Standard, Skybox, Particles),
а проект настроен на URP — поэтому объекты отображаются розовым.

РЕШЕНИЕ (в Unity):

1. Меню: Window → Rendering → Render Pipeline Converter

2. В окне конвертера:
   - В выпадающем списке выберите: "Built-In Render Pipeline to URP"
   - Включите опцию "Material Upgrade" (конвертация материалов)
   - Нажмите "Initialize Converters"
   - Нажмите "Convert Assets"

3. После конвертации:
   - Standard → Universal Render Pipeline/Lit
   - Particles → соответствующие URP Particle шейдеры
   - Skybox → URP-совместимый Skybox (при необходимости проверьте материал вручную)

ВАЖНО:
- Сделайте бэкап проекта или закоммитьте в Git перед конвертацией.
- Конвертация перезаписывает материалы.
- Если превью в Project останутся некорректными: ПКМ по папке Assets → Reimport.
